# ONE 패턴 스캐너

OKX USDT 무기한 선물 전체에서 "ONE 코인 급등 전조" 패턴과 비슷한 종목을 찾는 정적 웹페이지입니다.
브라우저에서 OKX 공개 API를 직접 호출하므로 서버와 API 키가 필요 없습니다.

## 조건 (12개)

| 시간봉 | 조건 |
|---|---|
| 주봉 (5) | 고점 대비 큰 하락 / 바닥권 박스 횡보 / 변동성 감소 / RSI 과매도 이력 / RSI가 과거 고점에 근접 |
| 일봉 (3) | 횡보 중 급변동 / OI 급증 / OI 급증 후 감소 |
| 4시간 (2) | RSI 상승 다이버전스 / 연속 양봉 |
| 1시간 (2) | OI 횡보 / OI 변화 감지 |

모든 임계값은 페이지의 "조건 파라미터"에서 조정할 수 있습니다.

## GitHub Pages 배포

1. 새 저장소 생성 후 `index.html`, `README.md` 업로드
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. `https://<유저명>.github.io/<저장소명>/` 접속

## 참고

- OI 조회(rubik 엔드포인트)는 호출 제한이 엄격(2초당 5회)해서, 캔들 조건을 일정 개수 이상 통과한 종목만 2단계로 조회합니다.
- 전체 스캔에는 약 1~3분이 걸립니다.
- 교육/연구용이며 투자 조언이 아닙니다.
